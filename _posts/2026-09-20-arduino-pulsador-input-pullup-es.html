Arduino desde cero · entradas digitales

Controlar un LED con un pulsador usando INPUT_PULLUP

Haz que Arduino reciba información del exterior: leeremos un pulsador y encenderemos un LED mientras lo mantenemos pulsado.

00

Objetivo

01 · ReposoBotón sueltoLED apagado
02 · AcciónBotón pulsadoLED encendido
03 · VueltaSoltar botónLED apagado

Hasta ahora Arduino daba órdenes mediante digitalWrite(). Aquí aprenderemos también a leer una entrada mediante digitalRead().

01

Material necesario

  • Arduino Uno o compatible.
  • Protoboard.
  • Un pulsador de cuatro patas.
  • Un LED.
  • Una resistencia de 220 Ω o 330 Ω para el LED.
  • Cables jumper.
  • Cable USB.
02

Cómo funciona el pulsador

Un pulsador típico de cuatro patas no tiene cuatro conexiones independientes. Sus patas están conectadas internamente por parejas. Cuando no lo pulsamos, ambos lados están separados; cuando lo presionamos, el pulsador une eléctricamente los dos lados.

Sin pulsar:

A ─── A       B ─── B

Al pulsar:

A ─── A ───── B ─── B

Por eso conviene colocarlo atravesando la separación central de la protoboard.

03

Conexiones

En este ejemplo reutilizamos el LED rojo en el pin digital 8 y conectamos el pulsador al pin digital 2.

Salida · LED

D8 → resistencia → LED → GND

Entrada · Pulsador

D2 → pulsador → GND

El LED necesita su resistencia limitadora de corriente. Para el pulsador no necesitamos añadir una resistencia externa porque utilizaremos la resistencia pull-up interna del Arduino.

04

¿Qué es INPUT_PULLUP?

Una entrada digital no debe quedar flotante. Con INPUT_PULLUP, Arduino activa internamente una resistencia que mantiene el pin en un estado definido cuando el botón está suelto.

pinMode(boton, INPUT_PULLUP);

Esto produce una lógica que al principio puede parecer invertida:

Botón sueltoHIGHLa resistencia interna mantiene la entrada activa.
Botón pulsadoLOWEl pin queda conectado a GND.
Regla rápidaLOW = pulsadoCon INPUT_PULLUP, la lógica está invertida.
Recuerda

Con INPUT_PULLUP, LOW significa que el pulsador está presionado.

Al pulsar, el pin D2 queda conectado a GND y por eso digitalRead() devuelve LOW.

05

Programa completo

Arduino / C++Programa completo
const int rojo = 8;
const int boton = 2;

void setup() {
  pinMode(rojo, OUTPUT);
  pinMode(boton, INPUT_PULLUP);

  digitalWrite(rojo, LOW);
}

void loop() {
  int estadoBoton = digitalRead(boton);

  if (estadoBoton == LOW) {
    // Pulsado: encendemos el LED
    digitalWrite(rojo, HIGH);
  } else {
    // Suelto: apagamos el LED
    digitalWrite(rojo, LOW);
  }
}
06

Qué ocurre al pulsar y soltar

Arduino ejecuta loop() continuamente. En cada vuelta lee el pin D2. Si detecta LOW, significa que el botón está pulsado y enciende el LED. Al soltarlo, D2 vuelve a HIGH y Arduino apaga el LED.

Leer D2 → ¿Pulsado? → LOW · LED ON / HIGH · LED OFF ↻
07

Qué hemos aprendido

digitalWrite() sirve para controlar una salida, como un LED. digitalRead() sirve para leer una entrada, como un pulsador. INPUT_PULLUP permite mantener la entrada en un estado estable utilizando una resistencia interna del microcontrolador.

digitalWrite()Controla una salida.
digitalRead()Lee una entrada.
INPUT_PULLUPEvita una entrada flotante sin resistencia externa.

El resultado final es sencillo: con el botón suelto el LED permanece apagado; al pulsar se enciende; al soltar vuelve a apagarse. Arduino ya no se limita a ejecutar una secuencia fija: ahora puede reaccionar a una acción del usuario.
