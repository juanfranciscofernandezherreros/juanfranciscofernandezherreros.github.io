Media Server with Jellyfin

A private Docker Compose architecture that turns an authorised request into organised, subtitled content available in Jellyfin without exposing administration panels to the internet.

01

An integration, not just a player

A Media Server has to connect requests, search, downloads, shared paths, subtitles, playback, remote access and network safety. This project assembles established open-source applications and gives them deliberate boundaries: Jellyfin shares Tailscale's network, Deluge shares Gluetun's network, and administration panels stay on localhost.

02

From request to playback

01 · REQUEST

Jellyseerr receives a film or series request.

02 · FIND

Radarr or Sonarr query sources managed by Prowlarr.

03 · DOWNLOAD

Deluge receives the job and exits through Gluetun and NordVPN.

04 · IMPORT AND WATCH

Radarr or Sonarr organise it; Bazarr subtitles it and Jellyfin plays it.

The installer prepares directories, environment variables and containers. Credentials, permitted sources, quality profiles and subtitle languages remain deliberate operator choices in the applications themselves.

Private access and operations

Tailscale provides remote access; Samba is read-only; Grafana, Prometheus, Loki, Alloy and cAdvisor provide separate observability.

TAILSCALEGRAFANA

Keep the router closed. Sonarr and Radarr must use gluetun:8112, never deluge:58846, because Deluge shares Gluetun's network namespace.

04

Shared paths, installation and verification

All media services mount the repository root as /data, keeping downloads and imports consistent:

/data/downloads   # Deluge work area
/data/movies      # Radarr library
/data/tv          # Sonarr library
/data/media       # optional extra space

Application state lives under docker/; it and .env are intentionally excluded from Git and should be backed up.

git clone https://github.com/juanfranciscofernandezherreros/media-server.git
cd media-server
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\check-stack.ps1

Use NordVPN manual OpenVPN service credentials, not normal account credentials. The diagnostic checks Compose, containers, Gluetun connectivity, Jellyfin through Tailscale and risky port exposure. Observability starts separately with docker compose -f docker-compose.observability.yml up -d; on Windows, Prometheus queries Windows Exporter through host.docker.internal:9182.

05

Responsible operation

The project does not download or distribute content itself, does not add sources automatically and does not remove legal responsibility. It is designed for private access and permitted sources. Docker Compose provides repeatability, not immunity to full disks, expired credentials or stopped containers: check status around updates, back up configuration and libraries, and never run docker compose down -v unless persistent data are intended to be deleted.
