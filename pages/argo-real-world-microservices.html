Argo Real World Microservices

An eight-part, hands-on course on shipping microservices to Kubernetes with ArgoCD and GitOps. Install the tools, deploy a service, automate its onboarding, diagnose memory failure, open secure local tunnels, load PostgreSQL at scale, and integrate the complete experiment with Argo CD.

Start with Part 0 → Read the theory first
00

What you'll be able to do

  • Deploy a Spring Boot microservice to a local Kubernetes cluster through ArgoCD, end to end — from a git push to a Synced, Healthy Application.
  • Read a GitOps config repo and an ArgoCD Application resource line by line, and explain what manifests/ and applications/ are each for.
  • Explain push-based CD vs. pull-based GitOps, and why ArgoCD's reconciliation loop self-heals manual drift instead of just reacting to it.
  • Onboard a brand new microservice into an existing GitOps setup — both by hand, and by generating one from scratch and registering it the same way.
01

Before you start

No prior Kubernetes or ArgoCD experience is assumed — Part 1 is written for someone who's never touched either.

  • Windows 10/11. Part 0's install commands use winget and PowerShell.
  • Comfortable with a terminal and Git — commits, push, basic commands. Nothing more advanced than that.
  • Enough Java/Spring Boot to read code — the course doesn't teach Spring Boot itself, it uses a small existing service to demonstrate the deployment pipeline.
  • ~20-30 minutes and a Docker Desktop install for Part 0's one-time setup, most of it downloads.

New to containers, Kubernetes, or GitOps as concepts?

The Introduction covers the theory — no installs, no commands — before Part 0 has you touching a terminal. If you already know what a container, a cluster, and GitOps are, skip straight to Part 0.
