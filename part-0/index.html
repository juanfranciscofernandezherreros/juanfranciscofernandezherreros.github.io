Argo Real World Microservices — Part 0

Before You Begin

Part 1 walks through deploying a microservice with ArgoCD, and it assumes eight things are already installed on your machine. This is the part where you actually install them — what each one is for, the exact command, and how to check it worked.

00

What you'll have by the end

A machine that can build a small Java app, package it as a container, run a local Kubernetes cluster, and talk to it — everything Part 1 — Hello World with ArgoCD needs. About 20-30 minutes, most of it downloads.

01

The tools, and why each one

Eight things, four jobs. Nothing here is specific to ArgoCD except the last one.

Git
Downloads the two repos Part 1 uses (hello-world-argocd, gitops-config) and lets you push changes to them.
A GitHub account
Where those two repos live. Free, sign up at github.com/signup if you don't have one yet — nothing else here needs an account.
Docker Desktop
Runs containers, and underneath, the entire local Kubernetes cluster — kind is just a thin layer on top of it.
kind
Creates and deletes the local Kubernetes cluster itself, inside Docker.
kubectl
Talks to whatever cluster kind created — every command that starts with kubectl in Part 1 needs this.
Java 21 + Maven
Compiles the demo microservice. Specific to this particular demo being a Spring Boot app — a different Part 1 demo would need a different language toolchain instead.
ArgoCD CLI
The argocd command — lets you trigger a sync from the terminal instead of the web UI. Everything it does can also be done by clicking in the browser, so this one's the closest to optional.
02

Install them (Windows)

One command per tool, using winget (built into Windows 10/11 — no separate install needed). Run these in PowerShell.

Git

winget install Git.Git

Docker Desktop

winget install Docker.DockerDesktop

Needs a sign-in the first time you launch it (free for personal use), and a restart on some machines. Start it now — the rest of this page assumes it's running.

kind

winget install Kubernetes.kind

kubectl

Already included with Docker Desktop on Windows — nothing extra to install. If it's ever missing: winget install Kubernetes.kubectl.

Java 21

winget install EclipseAdoptium.Temurin.21.JDK

Maven

winget install Apache.Maven

ArgoCD CLI

winget install argoproj.argocd

After installing, close and reopen your terminal — winget updates your PATH, but only new terminal windows pick it up.

03

Verify everything

One command per tool. Every one should print a version number — no version, no install, is a broken PATH, not a broken tool.

git --version
docker --version
kind version
kubectl version --client
java -version
mvn -version
argocd version --client

One extra check for Docker specifically

docker --version only proves the CLI is installed, not that the engine is running. Run docker ps too — an empty table (CONTAINER ID IMAGE COMMAND ... with no rows) means it's up. A connection error means Docker Desktop is still starting, or needs to be launched.

04

You're ready
